# Project

This file records project-level decisions the framework agents need to
read at runtime. Generated by `/bootstrap-architecture`; refine by editing
in place.

## Platform

- **Hosting**: Cloudflare Pages
- **Selected**: 2026-05-21
- **Rationale**: Astro+Starlight is a static-output framework. Cloudflare Pages provides
  free static hosting on a global anycast CDN (270+ POPs), per-PR preview deployments
  out of the box, and Workers as the runtime for the future error-receiver endpoint.
  Targets the PRD's "< 200 ms search results" non-functional requirement on the
  client side via CDN proximity.

## Stack at a glance

- **Framework**: Astro 6 + Starlight 0.39
- **Language**: TypeScript (strict) + MDX for content
- **Runtime**: Node.js 22 LTS (build-time only — output is static)
- **Hosting**: Cloudflare Pages
- **CI/CD**: GitHub Actions (`.github/workflows/ci.yml`, `.github/workflows/deploy.yml`)
- **Search**: Starlight built-in (Pagefind-based, client-side, zero infra)
